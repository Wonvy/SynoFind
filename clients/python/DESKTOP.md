# SynoFind Windows 0.5.0

双击 `SynoFind.exe`，在本机网页中添加本机文件夹或连接群晖，集中查找文件。电脑不需要安装 Python，NAS 不需要安装 SynoFind。

## 第一次使用

1. 解压 `SynoFind-Windows-0.5.0.zip`，双击 `SynoFind.exe`。
2. 程序打开运行窗口，并自动打开 `http://127.0.0.1:8788`。这个网页只供本机使用。
3. 仅搜索电脑文件时，点击「数据源」添加本机文件夹即可，无需登录 NAS。要搜索 NAS，填写自己的 NAS HTTPS 地址、DSM 账户和密码。例如 `https://nas.example.com:5001` 只是占位示例，不是可直接连接的地址。
4. 登录后，应用通过官方 File Station API 获取该账户可见的共享文件夹。明确选择所需共享文件夹，再保存并使用。
5. 需要更换共享文件夹时，进入连接设置，重新读取并选择。

新连接没有默认 NAS 地址、共享名称或自动选中的第一个共享。账户需要 File Station 应用权限和所选目录读取权限；列表可见不等于其中每个子目录都有权限。建议使用独立的只读账户。

## 记住账户与升级

选择记住账户后，凭据使用 Windows DPAPI 当前用户加密，存放在 `%LOCALAPPDATA%\SynoFind\Desktop`。下次启动时尝试自动连接到保存的 NAS 和共享目录。

一次性验证码不会保存。需要新验证码、密码变化或登录失败时，在网页中重新输入。保存的凭据与当前 Windows 用户关联，不应复制到其他电脑当作可直接使用的登录文件。

已有版本保存的账户和共享配置继续保留；新连接不使用个人默认值。升级时先退出旧应用，再替换程序文件，不要删除用户数据目录。

「断开连接」结束当前连接；「忘记此账户」删除本机保存的凭据，不删除 NAS 账户或文件。

## 预览方式与本地目录

默认使用网页预览，无需额外软件。网页支持文本、常见图片和不超过 20 MiB 的 PDF；列表和路径视图中，鼠标悬停文件后按空格即可预览，无需点击高亮；也可用方向键选择再按空格。悬停约 400 毫秒显示图片大缩略图、PDF 首页或文本摘要。

如果同一个共享文件夹已能通过 Windows 盘符或 UNC 路径访问，可以在设置中填写对应的本地根目录。例如 NAS 共享 `/Documents` 已映射到 `Z:\`，就填写 `Z:\`；也可填写已有访问权限的 `\\nas.example.com\Documents`。这些名称都是示例，应替换为实际路径。

选择 QuickLook 或 Seer 时，应用把选中文件交给对应的本机预览工具。预览软件需要事先安装；可以在设置中指定它的程序文件。没有安装或本地路径不可访问时，页面会提示原因。SynoFind 不自动安装软件、执行自定义命令模板、创建驱动器映射或保存 SMB 密码。

只接受 `QuickLook.exe` 或 `Seer.exe` 的完整路径。程序会检查常见桌面安装位置；便携版可手动指定，Microsoft Store 版本的发现与唤起不在本版验证范围。两种工具都使用固定文件参数启动；已运行的 QuickLook 使用其自身转交机制，已运行的 Seer 使用官方预览消息，并核对目标程序路径和限制等待时间。实现依据为 [QuickLook 官方源码](https://github.com/QL-Win/QuickLook/blob/master/QuickLook/App.xaml.cs)、[Seer 官方命令行记录](https://1218.io/seer/release-note/)及 [Seer 官方集成说明](https://1218.io/docs/seer/app-compatibility.html)。未随包附带或安装这些软件。

本地根目录应对应当前选择的 NAS 共享。切换共享后，请核对映射是否仍正确；不要将不同共享误填为同一个目录。

## 使用与退出

网页只监听 `127.0.0.1`。直接调用群晖官方 API，不在 NAS 建立索引或设置定时扫描，也不修改 NAS 系统设置。

搜索按文件名匹配；不做正文、OCR 或路径全文搜索。NAS 处理查询仍可能遍历目录，不能承诺完全免扫描或秒级返回。下载不承诺断点续传。

点击网页「退出应用」，或在运行窗口按 `Ctrl+C`，即可停止服务。关闭运行窗口也会停止程序；只关闭浏览器标签页不会退出。不会自动设置 Windows 开机启动。

## 常见情况

| 情况 | 处理方式 |
| --- | --- |
| 没有自动打开浏览器 | 打开运行窗口显示的本地网址。 |
| 网页无法连接本机服务 | 确认运行窗口仍打开；退出应用后服务已停止。 |
| 共享列表为空 | 核对账户的 File Station 和共享目录权限。 |
| 连接或搜索报错 | 记录页面的错误码、API 和操作名称，用于定位；不要提供密码或验证码。 |
| 搜索没有结果 | 核对关键词、已选共享目录和筛选条件。 |
| HTTPS 证书错误 | 使用与证书匹配的 NAS 地址，或为 CLI 配置信任的 CA/已核对证书指纹。 |
| 本地预览不能打开 | 确认映射路径可访问，且已经安装选择的预览工具。 |

本版是未签名开发交付。如 Windows 提示发布者无法识别，先核对文件来源和随附 SHA-256，不需要关闭系统安全保护。

## 命令行与构建

日常使用只需双击。隔离测试时可使用：

```powershell
.\SynoFind.exe --no-browser --port 8789 --data-dir .\test-data
```

这些参数只影响本机应用，不改变 NAS 配置。源码安装后可执行 `synofind-desktop`；普通 API 脚本和命令行详见 `clients/python/README.md`。

Windows x64 构建使用 Python 3.12、官方 PyInstaller。源码根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_desktop.ps1
```

构建先运行测试，再生成带控制台的单文件 EXE，验证启动、资源和退出，最后生成 ZIP、源码和校验文件。中间文件在 `work/desktop-build`，交付文件在 `outputs`。运行时许可来自本机 Python 与对应官方源码，已有许可缓存可复用。

## 验证范围

此前 0.4 系列已在一台真实 NAS 上完成共享列表、明确选择共享、搜索、映射盘文本预览、在文件资源管理器中定位并选中文件，以及更新 EXE 后保留映射和 DPAPI 自动登录验证。首次空配置与离线 PDF 画布也已在浏览器中验证。具体范围见随附验证报告，不代表所有设备和文件格式都已验证。

QuickLook/Seer 已按官方协议核对，并通过固定参数、进程路径与消息超时等模拟测试；未安装这两个软件进行真实预览验收。旧版交付继续存档。

旧 `.spk` 套件可以保留或由你手动停止；当前应用不依赖它，也不会自动卸载或删除它的数据。

## 本机与 NAS 汇总搜索（0.5.0）

- 「数据源」可添加多个本机文件夹或盘符，查看收录数量、更新状态和读取错误。移除只删除索引和配置，不删除文件。数据源不预设个人目录。
- 本机索引只保存名称、路径、大小和修改时间，首次添加、启动、手动刷新及每 15 分钟扫描。遇到不可读目录保留旧记录；跳过回收站、缩略图目录、符号链接和目录联接。
- 输入停止约 180 毫秒后，本机结果自动出现；中文输入法组合完成后才查询。快速输入会取消旧查询，旧响应不会覆盖新结果。
- 选择「全部数据源」时先显示本机即时结果，回车或点击「搜索文件」再汇总 NAS。NAS 使用官方 API，不建立本机的 NAS 索引，查询速度由 NAS 决定。两类结果都标记来源，也可单独筛选。
- 搜索中可点击「停止搜索」。开始新查询或修改关键词会发出取消请求；NAS 搜索通过官方 Search.stop 和 Search.clean 停止与清理。正在进行的网络请求可能需要数秒结束，无法确认时显示错误，不假报停止成功。
- 结果支持名称、大小、修改日期排序与分页。跨来源的名称顺序可能受 DSM 自身排序规则影响；超过前 10,000 项时请缩小范围。本机支持文件名及相对路径、多关键词、通配符；NAS 沿用 File Station 的文件名模式规则。
- 本机索引保存在原配置目录的 `local-index.sqlite3`，账号仍由 Windows DPAPI 加密。它不使用 Everything 的 NTFS 日志机制，新增文件要等索引更新；“即时”指已收录数据随输入查询，不代表文件变更立刻被收录。
- 顶部可选择亮色、暗色或跟随系统。主题保存在当前浏览器中；本机文件夹也可分别选择网页、QuickLook、Seer 预览。

## 本机网页接口补充

这些接口只供本机使用，沿用页面会话 Cookie 与 `X-SynoFind-CSRF` 校验；不会暴露 Windows 任意路径。

| 接口 | 功能 |
| --- | --- |
| `GET /api/status` | 包括 `local_sources` 的文件数、扫描进度、错误数 |
| `POST /api/sources/add` | `{root, preview_mode, preview_executable}` 添加或更新文件夹 |
| `POST /api/sources/remove` | `{id}` 移除数据源索引，保留原文件 |
| `POST /api/sources/scan` | `{}` 请求后台刷新本机索引 |
| `GET /api/search` | `source=all/nas/local/数据源ID`，可指定 `search_id` |
| `POST /api/search/cancel` | `{search_id}` 请求停止，返回 `stopped` 与 `error`；未完成可再次查询 |

本机结果返回内部的 `/@local/数据源ID/相对路径`；文件信息、预览和定位接口均按已授权数据源解析，并检查实际打开文件仍在目录范围内。

实现依据：[SQLite FTS5 文档](https://www.sqlite.org/fts5.html)；[群晖 File Station 官方 API](https://global.download.synology.com/download/Document/Software/DeveloperGuide/Package/FileStation/All/enu/Synology_File_Station_API_Guide.pdf)。
