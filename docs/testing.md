## 本地性能样本

十万条真实 SQLite 索引记录；Ryzen 9 5950X，查询含总数统计、排序、50 条结果解码。每项基准运行 3 次：

| 场景 | 每次查询约耗时 |
| --- | ---: |
| 选择性、至少三字符搜索 | 2.25 ms |
| 两字中文匹配十万条记录 | 90.95 ms |
| 无关键词分页浏览 | 46.85 ms |

128 MiB 合成文件通过本地 HTTP 完整流式下载，SHA-256 一致；尾部 Range 请求验证通过。记录的服务端工作集从 20,250,624 字节增至峰值 20,340,736 字节，增量 90,112 字节。该测试针对流式文件处理，不是网络速度承诺。

这些是开发电脑上的样本，**不能作为 DS918+ 的实际搜索或传输性能承诺**。实际文件数量、磁盘、备份任务和索引大小会影响结果。
